# ДЗ 8
## sniff_dz8.py

Снифер. Слушает tcp port 80 и печатает первые строки HTTP запросов
и ответов, всё пойманное по Ctrl+C пишется в dz8.pcap.

## analyze_dz8.py

Разбор dz8.pcap после упражнений с XSS на Gruyere. Склеивает
TCP-сегменты, распаковывает gzip и ищет признаки payload (alert(,
script, onmouseover, onload=) в запросах и ответах. В запросах смотрит
только стартовую строку, URL-кодирование раскручивает (%3Cscript%3E).
